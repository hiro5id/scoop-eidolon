Eidolon for Scoop
===

The Scoop bucket of [Eidolon](https://github.com/hiro5id/eidolon-releases): it finds the copies and Live Photo pairs in a photo and video library by how they look, and you review them in your browser. Windows, x86-64. Latest version: 2026.11.3.

```powershell
scoop bucket add eidolon https://github.com/hiro5id/scoop-eidolon   # once
scoop install eidolon                                               # install
eidolon                       # start it: its window opens (Open shows the review screen)
scoop update eidolon          # update (or Update now on the review screen)
scoop uninstall eidolon       # remove
```

Each release updates `bucket/eidolon.json` here by itself: don't edit it by hand. Other ways to install, and every release: [hiro5id/eidolon-releases](https://github.com/hiro5id/eidolon-releases).
